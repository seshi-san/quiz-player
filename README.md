# Quiz Player

チャットの AI から受け取った4択問題を、スマホのブラウザで解くための1枚ページです。

- 問題データ（JSON）を貼り付けて読み込む → 解く → 「結果をコピー」でチャットに返す
- 回答の途中経過は、その端末のブラウザの中（localStorage）にだけ保存されます。サーバーには何も送りません
- 問題データはリポジトリに置きません。このリポジトリにあるのはプレーヤーと、形式の説明とサンプルだけです

## 使い方

1. ページを開き、問題データを貼り付けて「読み込む」
2. 解く（選択肢をタップ。わからなければ「わからない（空欄）」）
3. 「一覧・結果」→「結果をコピー」→ チャットに貼り付ける

すでにある問題集と同じ `id` のデータを読み込むと、まだない問題だけが後ろに追加されます（同じものを2回貼っても重複しません）。

## 問題データの形式（AI に渡す説明）

以下をそのまま AI への指示に貼ってください。

````
問題は次の JSON 形式で、```json のコードブロック1つに入れて出してください。

{
  "id": "2026-11-12",          // 必須。問題集を見分ける名前
  "title": "11/12 復習",        // 任意。表示名
  "recall": true,               // 任意。true にすると全問「思い出してから選択肢を見る」方式（下記）
  "typed": true,                // 任意。true にすると全問「意味を入力してから選択肢を見る」方式（下記）
  "items": [
    {                           // 学習カード（任意）。直後の問題の前に表示される
      "type": "learn",
      "title": "1. つなぎの言葉",
      "words": [
        {"word": "besides", "pos": "前/副", "meaning": "〜に加えて", "core": "核のイメージ",
         "example": "英語の例文", "example_ja": "例文の和訳"}
      ]
    },
    {                           // 長文（任意）。注釈の語は点線で表示され、タップすると意味が出る
      "type": "passage",
      "title": "社内メール",
      "text": "We need to recruit 20 volunteers ...",   // 改行は \n
      "gloss": {"recruit": "採用する"}                  // 語 → 意味（大文字小文字は区別しない）
    },
    {                           // 4択問題
      "word": "besides",        // 記録に使う見出し語
      "sentence": "___ a salary, employees receive free meals.",   // 空欄は ___
      "options": ["Besides", "Meanwhile", "Unlike", "Via"],        // 2〜6個
      "answer": "Besides",      // 正解の選択肢の文字列（0始まりの番号でも可）
      "ja": "和訳",              // 任意。解答後に表示
      "note": "解説",            // 任意。解答後に表示
      "recall": true,           // 任意。この問題だけ「思い出してから選択肢を見る」方式にする
      "typed": true,            // 任意。この問題だけ「意味を入力してから選択肢を見る」方式にする
      "passage": true           // 任意。直前の長文を問題の上に表示する（注釈もタップできる）
    }
  ]
}

- 選択肢の並び順はページ側でシャッフルするので、正解の位置を気にしなくてよい
  （シャッフルさせたくないときは "shuffle": false）
- recall 方式：最初は問題文だけが表示され、選択肢は隠れている。
  本人は頭の中で答えを思い浮かべてから「選択肢を見る」を押す。思い出せなければ「思い出せない（空欄）」
- typed 方式：recall 方式の、思い浮かべた答えを入力させる版。送信すると直せず、そのあと選択肢が出る。
  何も入力せずに送信すると「思い出せない」になる
- コメント（// 〜）は説明用。実際の出力には入れない
````

## 結果の形式

「結果をコピー」で次の形の JSON がコピーされます。

```
{"quiz":"2026-11-12","saved_at":"2026-11-12T08:15:00.000Z","looked_up":["recruit"],"items":[
{"n":1,"word":"besides","status":"ok","chosen":"Besides","answer":"Besides","comment":""},
{"n":2,"word":"meanwhile","status":"ng","chosen":"Unlike","answer":"Meanwhile","comment":"迷った"}
]}
```

looked_up は、長文の中でタップして意味を見た語の一覧です。

typed 方式の問題には `"mode":"typed_v1"`、入力した文字 `typed`、表示から送信までのミリ秒 `typed_ms` が付きます。

recall 方式で「思い出せない（空欄）」を押すと選択肢が出ます。そこで選んだ場合、status は `bl` のまま、選んだ選択肢が `pick` に入ります（思い出せないが見ればわかる、を区別するため）。

| status | 意味 |
|---|---|
| `ok` | 正解 |
| `ng` | 不正解 |
| `slip` | 不正解だが本人が「押し間違い」と指定 |
| `guess` | 正解したが本人が「勘・消去法で当たった」と指定（覚えていない扱い） |
| `bl` | 「わからない（空欄）」「思い出せない」を選んだ |
| `un` | 未回答 |
