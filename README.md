# Quiz Player

チャットの AI から受け取った4択問題を、スマホのブラウザで解くための1枚ページです。

- 問題データ（JSON）を貼り付けて読み込む → 解く → 「結果をコピー」でチャットに返す
- 回答の途中経過は、その端末のブラウザの中（localStorage）にだけ保存されます。サーバーには何も送りません
- 問題データはリポジトリに置きません。このリポジトリにあるのはプレーヤーと、形式の説明とサンプルだけです

## 使い方

1. ページを開き、問題データを貼り付けて「読み込む」
2. 解く（選択肢をタップ。わからなければ「わからない（空欄）」）
3. 「一覧・結果」→「結果をコピー」→ チャットに貼り付ける

100問など長いときは、分けて受け取って構いません。**同じ `id` のデータを続けて読み込むと、まだない問題だけが後ろに追加されます**（同じものを2回貼っても重複しません）。

## 問題データの形式（AI に渡す説明）

以下をそのまま AI への指示に貼ってください。

````
問題は次の JSON 形式で、```json のコードブロック1つに入れて出してください。
長い場合は 25問程度ずつに分け、すべて同じ id を付けてください。

{
  "id": "2026-11-12",          // 必須。分割して出すときは全部同じにする
  "title": "11/12 復習",        // 任意。表示名
  "items": [
    {                           // 学習カード（任意）。直後の問題の前に表示される
      "type": "learn",
      "title": "1. つなぎの言葉",
      "words": [
        {"word": "besides", "pos": "前/副", "meaning": "〜に加えて", "core": "核のイメージ",
         "example": "英語の例文", "example_ja": "例文の和訳"}
      ]
    },
    {                           // 4択問題
      "word": "besides",        // 記録に使う見出し語
      "sentence": "___ a salary, employees receive free meals.",   // 空欄は ___
      "options": ["Besides", "Meanwhile", "Unlike", "Via"],        // 2〜6個
      "answer": "Besides",      // 正解の選択肢の文字列（0始まりの番号でも可）
      "ja": "和訳",              // 任意。解答後に表示
      "note": "解説"             // 任意。解答後に表示
    }
  ]
}

- 選択肢の並び順はページ側でシャッフルするので、正解の位置を気にしなくてよい
  （シャッフルさせたくないときは "shuffle": false）
- コメント（// 〜）は説明用。実際の出力には入れない
````

## 結果の形式

「結果をコピー」で次の形の JSON がコピーされます。

```
{"quiz":"2026-11-12","saved_at":"2026-11-12T08:15:00.000Z","items":[
{"n":1,"word":"besides","status":"ok","chosen":"Besides","answer":"Besides","comment":""},
{"n":2,"word":"meanwhile","status":"ng","chosen":"Unlike","answer":"Meanwhile","comment":"迷った"}
]}
```

| status | 意味 |
|---|---|
| `ok` | 正解 |
| `ng` | 不正解 |
| `slip` | 不正解だが本人が「押し間違い」と指定 |
| `bl` | 「わからない（空欄）」を選んだ |
| `un` | 未回答 |
